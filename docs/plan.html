What “done” meant, and what we built

  1. 1

    Data spike

    Done
    Done means
    NASA HLS pixels for a farm can be read from the browser, with cloud masking, and 30 years of NASA POWER daily weather works.
    Built
    STAC search plus a data API that returns small per-farm PNGs holding NDVI, the yellow-flower index and the Fmask cloud mask. Works from the browser (CORS) with no login. Lesson: the + in band maths must be URL-encoded or the service returns 500.
    Files
    src/services/hls.js src/services/weather.js
  2. 2

    HLS service

    Done
    Done means
    For a farm: find usable scenes over 5 seasons, fetch the layers, compute per-paddock values and per-pixel maps. Cached, throttled, with progress.
    Built
    Searches Landsat and Sentinel-2 collections and keeps the clearest image per 8-day window around flowering (16-day otherwise). Uses a ~30 m grid with per-paddock pixel masks, Cache Storage with retries, and a 6-at-a-time worker pool reporting progress.
    Result
    ~104 images · ~28 s first time · instant after
    Files
    src/services/hls.js src/services/space.js src/state/useSpace.js
  3. 3

    Phenology classifier

    Done
    Done means
    From each paddock’s greenness curve per season: crop family (cereal / canola / pulse / pasture / fallow), a confidence level and the evidence (“NDVI peaked 0.82 on 12 Sep”).
    Built
    Season window set by latitude, then green-up, peak and dry-off dates. Canola is spotted when its yellow flowers stand out from the rest of the scene while the crop is near peak green. Pasture stays flat and green. Cereal vs. pulse comes from peak height and season length. The current season is handled with care.
    Files
    src/logic/phenology.js
  4. 4

    Validation

    Done
    Done means
    Classifier checked against independent ground truth (USDA Cropland Data Layer), accuracy reported honestly, thresholds tuned.
    Built
    About 5,500 uniform 150 m blocks per season in North Dakota. Developed on 2021, held out 2020. A tuned version overfitted (better on 2021, worse on 2020), so the simpler rules were kept.
    Result
    Canola: 89–94% right when called · 85–96% found Crop family: 78% / 88%
    Files
    tools/validation/validate-phenology.mjs · npm run validate:phenology

  6. 6

    Neighbour canola → blackleg warning

    Done
    Done means
    Canola flowering around the farm last season is shown on the map; paddocks within 500 m get a warning and the planner avoids canola there.
    Built
    Per-pixel canola map, ignoring patches mostly inside the paddock itself. Each paddock gets the nearest-canola distance and hectares within 500 m. Shown as a yellow overlay with a legend. The planner penalises canola for the coming season and adds a note saying why.
    Files
    phenology.js (detectCanolaPixels) space.js rotation.js (BLACKLEG_DISTANCE_M) spacePlanning.js
  7. 7

    Safest sowing window

    Done
    Done means
    30 years of NASA POWER daily temperatures → frost-at-flowering and heat-at-grain-fill risk per sowing date per crop → recommended window in the Planner.
    Built
    Thermal time to flowering per crop. Frost means ≤ 1 °C at flowering; heat means the crop’s limit is passed on 2+ days in grain fill. Weekly sowing dates are tested, and the window is every date within 8 points of the lowest risk. Shown as a risk chart.
    Result
    Demo farm: wheat ~29 Apr · barley 6 May · canola & lupins 6–13 May
    Files
    src/logic/sowing.js src/services/weather.js SowingCard.jsx
  8. 8

    “Did my rotation work?”

    Done
    Done means
    Season vigour from space (rainfall-adjusted) per paddock; a report card comparing crops after a break vs. after the same crop.
    Built
    Vigour is the area under the greenness curve, compared with the farm’s other cropped paddocks the same season. It compares cereals after a break crop with cereals after cereals, with rain and the French & Schultz water-limited wheat benchmark for context.
    Result
    Demo farm: 1.12× after a break (n=2) vs 0.92× after a cereal (n=8) → +21%
    Files
    src/logic/performance.js RotationReportCard.jsx Dashboard.jsx

Data notes

NASA HLS v2.0 is read through Microsoft Planetary Computer’s mirror: free, browser-friendly, no login. NASA’s own LP DAAC copy needs an Earthdata login.

NASA POWER (daily and climatology) is used directly.
